# Software Helpdesk Chatbot Frontend

소프트웨어 설치, 라이선스, 반납 문의를 처리하는 웹 기반 챗봇 프론트엔드입니다.

---

## 기술 스택

- React
- Socket.IO Client
- JavaScript (ES6)
- HTML / CSS (inline style)

---

## 주요 기능

- 사용자 메시지 입력 및 전송
- Enter 키로 메시지 전송
- 실시간 채팅 (Socket.IO)
- 채팅 메시지 자동 스크롤
- 사용자/챗봇 말풍선 UI 구성
- 기존 채팅 이력 조회 및 출력
